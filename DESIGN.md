# Native LCD visual authority

This records the incumbent system for throwaway settings concepts. It does not select a new settings layout.

- A 240 by 240 square native display, the existing M8Stealth bitmap family, hard pixel edges and integer placement.
- Existing palette roles and clear light/dark inversion for selection. AMBER is the current review theme; MONO remains a required state check.
- Compact top identity/header, the five existing settings categories, and a quiet bottom strip that names physical controls.
- Instrument parameter-bank D remains the chosen instrument-control direction. Settings may have their own reading hierarchy.
- Do not copy another maker's typeface, artwork, screen chrome or dedicated buttons.

Primary references: `docs/lcd-typography.md`, the native PR #574 captures at head `6b9dfc3`, and `tests/prototypes/large_readability.html` (older exploratory gallery).
