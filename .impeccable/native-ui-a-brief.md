# Native FM-1 UI — direction A (Musica Viva grid)

Scope: the whole native 240×240 panel UI, Operate mode. Musicians playing and editing through four knobs and
the panel buttons. Approved 2026-10-23: "Full A redesign + GRAPH", GRAPH default TURN for everyone. Mocks:
`mocks/directions/` (A row) and `mocks/graph-modes/`.

## Direction contract

THESIS: The screen is a concert-poster grid: four knob columns, one dominant numeral, rules instead of boxes.
Refuses the rounded-card dashboard (surface tiles, chips, pills as structure).

OWN-WORLD: Background ground, ink type, dim labels, hairline rules; the theme's accent appears only where a
control is acting now. Editing state is rule form: solid VALUE, dashed AUTO, doubled LOCK; the retained focus
is an ink rule. M8Stealth only; a 27px numeral (3× M ink, metadata only) where the page has room.

STORY: The player sees what the knob under their hand changes, its value large, its effect as a curve while
turning, and the live sound otherwise; settings, lists and names read as one calm typographic system.

FIRST VIEWPORT: HOME: header hairline; CUT label and K1 VALUE scope; 355 Hz as the 27px numeral flush left;
four knob columns under rules, K1's rule heavy; the live waveform below, switching to the filter curve while
K1 turns (DISPLAY > GRAPH = TURN); step row and ACID / ANALOG / HOME footer.

FORM: Swiss/International Typographic Style concert poster (Zurich Tonhalle), position 3 of 7 grounded
candidates; seed: none (unavailable). Signature interaction: the graph follows the turned knob, then returns
to the animated waveform.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict,
DESIGN.md, and every shipping raster carrying its provenance
